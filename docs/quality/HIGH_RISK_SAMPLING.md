# 高风险任务抽样复核模板

本文记录 Superego 在高风险数据、代码和文档任务中可复用的抽样复核模板。模板只提供候选策略，不能替代当前任务的验收合同、AuditPacket、验证结果和权限策略。

## 通用分层

每次抽样复核默认分三层：

- 必查样本：用户明确强调的指标、验收合同硬约束、只读输入边界、允许输出边界、失败 validator。允许输出边界以用户任务和 HA 验收合同为准，不默认等同于 `output/`。
- 风险样本：Ego 风险项、审计发现、空值、0 值、异常值、极大/极小值、边界条件、历史失败模式。
- 随机样本：从剩余普通样本空间中选少量点，用于抵抗确认偏差。

Superego 必须说明样本空间、样本数、选择依据和随机扰动是否可复现。

## 数据表任务

优先抽查：

- 分子、分母、总量和占比公式。
- 空值、0 值、负值、极大值、极小值。
- 模板列名、sheet 名、冻结窗格、关键格式和输出行数。
- 汇总表与明细表之间的等式关系。
- 用户明确要求的业务规则、计算口径、映射关系和适用范围；具体领域规则必须来自当前任务、验收合同或按需技能，不能从历史案例类推。

最小断言：

- 抽样行可从只读输入复算出输出值。
- 汇总口径与合同一致。
- 输出没有污染只读输入目录。

## 代码任务

优先抽查：

- 改动文件是否都由用户任务需要。
- 失败测试、类型检查、lint 或 smoke 是否被正确解释。
- 错误处理、权限边界、路径边界和回归风险。
- 用户可见行为是否与最终回复一致。

最小断言：

- 必要验证已运行，或无法运行的原因可审计。
- Ego `changed_files` 与审计写入路径不矛盾。
- Superego 不能把失败验证伪装为成功。

## 文档任务

优先抽查：

- 文档是否只记录长期有效规则，细节是否放在 [文档导航](../README.md) 指定的专题文档。
- 中文 Markdown 是否为无 BOM UTF-8。
- 示例命令是否符合 Windows Git Bash 优先策略。
- 是否误写真实密钥、本地日志、运行数据或不可提交产物。

最小断言：

- 文档边界符合 [AGENTS.md](../../AGENTS.md) 约束。
- 示例不会诱导绕过审批或长期继承权限。
