MAS Goal 控制面与低熵自主性框架

改造后的 MAS 把 Goal 作为控制面，把低熵信号作为收敛证据，把角色上下文扰动作为本我跳出固定吸引子的机制；所有外部副作用仍由 Ego 工具链、权限审批和 Superego 审计约束。

总览架构

角色上下文扰动矩阵

HA：很低

意图守门

入口：意图歧义、边界检查、澄清需求。

约束：不改变用户目标，不主动扩写任务。

输出：澄清问题或验收合同提示。

Ego：高

执行探索

入口：执行计划、工具顺序、验证策略、反例探针。

约束：不绕过权限，扰动必须转成可验证行动。

输出：observation plan 或 action variant。

Superego：低到中 / 给 Ego 可高

盲点评审

入口：抽样策略、反事实问题、返工扰动建议。

约束：最终判断必须回到 AuditPacket 和验证证据。

输出：critique 或 Ego perturbation proposal。

Dream：中到高 / 离线

长期扰动源

入口：Experience Graph 聚类、失败模式、固定套路检测。

约束：不能执行，不能裁判事实，不能直接强注入 Ego。

输出：perturbation candidate library。

闭环规则

1. 控制面闭环

  • GoalController 维护状态、预算和 continuation prompt。
  • Scheduler 通过 owner_id / lease_until 原子 claim。
  • GoalJudge 只输出控制动作，不直接写用户工作区。

2. 上下文扰动闭环

  • 扰动作为隔离数据块进入 prompt，不作为指令。
  • 扰动片段低于系统规则、用户目标、合同和权限。
  • 复杂扰动策略要用 trace 指标验证后再晋升。

3. 低熵证据闭环

  • 信号必须有 source、hash、TTL、脱敏和 secret scan。
  • 评分使用 entropy_score_v1，可测试、可回放。
  • 确定性门禁优先于模型自信和扰动灵感。
